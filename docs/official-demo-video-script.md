# FairMirror 官网提交演示视频脚本

## 视频目标

用于智联招聘首届全国 AI 创新大赛产品 Demo 提交。建议时长 3-5 分钟，突出 AI+招聘赛道定位、可运行产品、比赛脱敏数据、求职者与企业双边价值。

## 一句话定位

FairMirror 是面向 AI+招聘赛道的招聘公平审计网关，同时为求职者提供简历防御盾，让企业招聘更高效、更公平、更可复核。

## 录制准备

- 打开前端：`http://127.0.0.1:5173`
- 确认后端健康：`http://127.0.0.1:8000/api/v1/health`
- 浏览器缩放建议：90% 或 100%。
- 录屏顺序：Dashboard → 简历检查 → 岗位审计 → 面试监控 → 算法壁垒 → 合规报告。
- 录制时重点展示“比赛脱敏样本”按钮和审计结果，不要长时间停留在代码或终端。

## 逐字讲解稿

### 0:00-0:25 开场

大家好，这是 FairMirror，投递方向是智联招聘 AI 大赛的 AI+招聘赛道。AI 正在进入招聘流程，但大学生仍然会遇到简历投递无反馈、被敏感属性误筛、面试评价不透明的问题；企业也会面临招聘效率、歧视争议和合规留痕压力。FairMirror 的定位是招聘公平审计网关，同时提供求职者侧的简历防御盾。

### 0:25-1:45 简历防御盾

我先从求职者视角开始。这里可以选择比赛脱敏简历样本。系统会扫描姓名、性别、年龄、现居地址、学历、求职状态等可能影响自动化筛选的敏感信息和代理变量。右侧会给出 ATS 模拟通过率、命中原因和匿名化建议。下面的改写版本会把个人身份信息弱化，保留工作经历、项目能力和岗位相关证据。这样求职者知道为什么可能被误筛，企业也知道哪些字段不应该进入自动化判断。

### 1:45-2:55 JD 智能审计

接下来是企业招聘侧。这里同样接入了比赛脱敏 JD 样本。点击后系统会识别岗位中的年龄、学历、地域、身份、性别和工作风格风险。例如年龄范围、学历门槛、本地户籍、党员优先、女士优先、形象良好、接受加班等表达。审计结果会显示风险分、命中位置、原因和替代表达，并生成偏见免疫版 JD。企业可以在岗位发布前完成整改，减少误筛和歧视争议。

### 2:55-3:30 面试公平监控

这里是面试公平监控。系统用 4/5 法则、差异影响比、人口统计均等差异、评分差异和追问深度差异来判断面试流程是否存在群体差异。FairMirror 不替企业决定录用谁，而是指出哪个批次需要人工复核，帮助企业把招聘流程做得更透明。

### 3:30-4:10 算法壁垒

算法壁垒页展示的是技术路线。当前版本用配置化规则库和轻量语义复核保证稳定可解释；模型层提供 RoBERTa 适配接口、Token/短语归因和对抗去偏演示。我们不把模型判断当黑盒，而是把每个风险都转成可复核的证据结构，后续可以替换真实模型权重和企业样本训练数据。

### 4:10-4:45 合规报告

最后是合规报告。企业最终需要的不只是检测结果，还需要可归档、可复核、可整改的证据链。FairMirror 会输出审计范围、核心结论、风险证据、EU AI Act 和中国 AI 伦理检查清单、整改路线图，并支持 JSON 和 PDF 导出。

### 4:45-5:00 收尾

总结一下，FairMirror 不是普通简历工具，也不是 ATS。它连接求职者和企业两端：让求职者知道自己为什么可能被误筛，让企业知道招聘流程哪里需要整改，让 AI 招聘效率有证据、有边界、有复核。

## 答辩备用话术

### 如果问：你们训练了真实大模型吗？

当前版本采用稳定可解释优先的混合审计路线：规则库和语义复核保证结果可复现；RoBERTa 适配、Token 归因和对抗去偏结构已经打通，后续可以接入真实权重和企业样本训练。

### 如果问：为什么不是普通简历修改工具？

普通简历工具主要优化表达，FairMirror 同时覆盖求职者简历防御、企业 JD 审计、面试公平监控和合规报告，是招聘公平审计闭环。

### 如果问：为什么适合智联招聘？

智联连接求职者和企业，FairMirror 可以作为平台侧公平治理能力，降低误筛、歧视争议和招聘 AI 黑盒风险，帮助招聘服务同时提升效率和信任。

### 如果问：数据是否合规？

项目使用比赛脱敏数据，原始 Excel 只读保存，派生 JSON 只保留最小演示字段，审计报告形成原始数据、派生样本、审计输出三层证据链。
