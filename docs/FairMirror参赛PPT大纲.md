## 第 2 页｜一句话介绍

**标题**：让招聘公平从口号变成指标、证据和流程

**页面内容**：

- 官网痛点：大学生求职面临简历无头绪、投递无反馈、面试评价不透明。
- 企业痛点：AI 招聘提高效率，也带来误筛、歧视争议和合规留痕压力。
- FairMirror：用 AI 审计 AI 招聘，把风险变成证据、解释和整改建议。
- 双边价值：企业获得公平审计网关，求职者获得简历防御盾。

**配图建议**：双边价值图：求职者困境 → FairMirror → 企业公平招聘。
**讲解词**：这不是单点简历工具，也不是普通招聘系统，而是把求职者和企业两端的公平问题连接成一个可落地闭环。

## 第 3 页｜问题背景

**标题**：AI 招聘重构流程，也让误筛风险更隐蔽

**页面内容**：

- 求职者侧：简历被照片、年龄、性别、地域、学历等代理变量影响，却不知道原因。
- 企业侧：自动筛选、智能面试和算法排序提升效率，但缺少公平检测与整改闭环。
- 平台侧：招聘服务需要同时提升效率、体验和信任，不能只追求自动化。
- 合规侧：招聘 / 雇佣 AI 正成为高风险治理场景，需要解释、日志和人工复核。

**配图建议**：求职者投递漏斗 + 企业招聘流程 + 偏见风险点标注。
**讲解词**：智联连接求职者和企业，FairMirror 要解决的是双方共同面对的信任问题：为什么被筛掉、哪里不公平、如何整改。

## 第 4 页｜赛道匹配与市场调研

**标题**：AI+招聘赛道需要的不只是效率工具，而是公平可信的招聘环境

**页面内容**：

- 赛道匹配：FairMirror 对应 AI+招聘赛道，聚焦企业招聘痛点、招聘环境改善和真实流程落地。
- 求职者副线：简历防御盾回应大学生“简历无头绪、投递无反馈”的痛点。

| 类型 | 代表 | 不足 | FairMirror 差异 |
| --- | --- | --- | --- |
| JD 文案优化 | Textio | 主要优化文案 | 增加审计证据、整改闭环和报告归档 |
| ATS 系统 | Workday / Greenhouse | 管流程，不聚焦公平证据 | 作为审计网关接入 ATS 前后 |
| 面试平台 | HireVue / Applied | 偏结构化面试 | 增加群体公平指标和差异影响报告 |
| 公平工具包 | Fairlearn / Aequitas | 偏算法实验 | 把指标产品化到招聘业务链路 |
| 模型监控 | Evidently / Fiddler | 泛模型监控 | 绑定 JD / 简历 / 面试招聘证据链 |

**配图建议**：赛道定位 + 竞品对比表。
**讲解词**：我们不是再做一个招聘工具，而是给招聘 AI 加一层公平、解释和合规能力。

## 第 15 页｜商业化与落地规划

**标题**：从 MVP 到招聘 AI 治理基础设施

**页面内容**：

**商业模式**：

- 企业 SaaS：按组织、岗位数、审计次数订阅。
- API 授权：接入 ATS、面试系统、招聘官网。
- 第三方公平认证：年度招聘公平审计报告。
- 个人简历防御盾：面向求职者提供匿名化和 ATS 模拟。
- 合规咨询与行业报告。

**落地路径**：

1. MVP：上传文件生成审计报告。
2. 企业试点：接入 ATS。
3. 数据闭环：沉淀规则库、模型版本和审计日志。
4. 认证服务：形成年度公平招聘报告。
5. 平台化：开放 API 和规则管理。

**配图建议**：路线图。  
**讲解词**：FairMirror 的落地方式不是替换企业系统，而是作为审计网关接入现有流程。
