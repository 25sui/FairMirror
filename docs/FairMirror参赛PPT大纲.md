## 第 2 页｜一句话介绍

**标题**：让招聘公平从口号变成指标、证据和流程

**页面内容**：

- 招聘公平不是口号，而是可量化指标。
- 每个风险都有证据、解释和整改建议。
- 企业获得合规留痕，求职者获得被公平看见的机会。

**配图建议**：三段式卡片：指标、证据、整改。

## 第 3 页｜问题背景

**标题**：AI 招聘提升效率，也可能放大隐性偏见

**页面内容**：

- 自动筛选、智能面试和算法排序正在进入招聘流程。
- 年龄、性别、学历、地域、婚育等因素可能被显性或隐性利用。
- 企业缺少解释证据和整改闭环。
- 求职者不知道自己为什么被误筛。
- 招聘 / 雇佣 AI 已进入高风险合规场景。

**配图建议**：招聘流程漏斗 + 偏见风险点标注。  
**讲解词**：招聘是高影响决策，效率不能以公平为代价。

## 第 4 页｜市场调研

**标题**：现有工具各有侧重，但缺少招聘公平闭环

**页面内容**：

| 类型 | 代表 | 不足 |
| --- | --- | --- |
| JD 文案优化 | Textio | 主要优化文案，缺少全流程审计 |
| ATS 系统 | Workday / Greenhouse | 管流程，不聚焦公平证据 |
| 面试平台 | HireVue / Applied | 偏结构化面试，合规留痕不足 |
| 公平工具包 | Fairlearn / Aequitas | 偏算法实验，业务产品化不足 |
| 模型监控 | Evidently / Fiddler | 泛模型监控，不绑定招聘证据链 |

**配图建议**：竞品对比表。  
**讲解词**：FairMirror 的差异是把公平指标、偏见检测、解释归因和合规报告做成招聘业务闭环。

## 第 7 页｜核心功能：JD 智能审计

**标题**：发布前识别岗位描述中的偏见表达

**页面内容**：

- 支持输入或上传 `.txt/.md/.csv/.docx/.pdf`。
- 支持从比赛脱敏 JD 样本一键填入真实招聘文本。
- 检测年龄、学历、地域、性别暗示、工作风格偏见。
- 原文命中高亮，定位风险位置。
- 输出风险原因、规则来源、替代表达和整改版 JD。

**配图建议**：放 JD 审计页面截图，突出高亮和对照视图。  
**讲解词**：评委可以直接看到哪里错、为什么错、怎么改。

## 第 8 页｜核心功能：简历防御盾

**标题**：发现简历中可能触发误筛的敏感信息

**页面内容**：

- 支持比赛脱敏 CV 样本一键填入。
- 扫描照片、性别、婚育、籍贯、年龄、毕业年份、空窗期。
- 标记敏感信息和代理变量。
- 模拟 ATS 通过率变化。
- 生成匿名化、能力导向的简历版本。

**配图建议**：放简历检查页面截图。  
**讲解词**：求职者知道为什么可能被误筛，企业也知道哪些字段不该进入自动化判断。

## 第 9 页｜核心功能：面试公平监控

**标题**：用群体指标发现面试流程是否存在差异影响

- 展示 selection_rate、disparate_impact_ratio、demographic_parity_difference。
- 对评分差距和追问深度差异进行解释。

**配图建议**：放面试监控页指标卡和图表截图。  
**讲解词**：系统不替企业决定录用谁，而是指出流程是否需要人工复核。

## 第 13 页｜AI 技术方案

**标题**：先稳定可信，再逐步增强模型能力

**页面内容**：

1. 配置化规则库：稳定、可解释、可维护。
2. 结构化语义复核：补充隐性年龄、学历代理、地域倾向。
3. RoBERTa 适配层：统一模型输出结构，支持降级演示。
4. Token / 短语归因：让风险判断不再是黑盒。
5. 对抗去偏：展示去偏前后公平指标改善。

**配图建议**：五模块能力矩阵。  
**讲解词**：我们没有盲目追求大模型，而是用可复核的混合审计方案保证项目可落地。

## 第 15 页｜商业化与落地规划

**标题**：从 MVP 到招聘 AI 治理基础设施

**页面内容**：

**商业模式**：

- 企业 SaaS：按组织、岗位数、审计次数订阅。
- API 授权：接入 ATS、面试系统、招聘官网。
- 第三方公平认证：年度招聘公平审计报告。
- 个人简历防御盾：面向求职者提供匿名化和 ATS 模拟。
- 合规咨询与行业报告。

**落地路径**：

1. MVP：上传文件生成审计报告。
2. 企业试点：接入 ATS。
3. 数据闭环：沉淀规则库、模型版本和审计日志。
4. 认证服务：形成年度公平招聘报告。
5. 平台化：开放 API 和规则管理。

**配图建议**：路线图。  
**讲解词**：FairMirror 的落地方式不是替换企业系统，而是作为审计网关接入现有流程。
