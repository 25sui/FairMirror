# FairMirror 演示脚本

## 1. 启动系统

```bash
docker-compose up -d --build
```

访问：

- 前端：`http://localhost:3000`
- API 文档：`http://localhost:8000/docs`

## 2. 注册与登录

1. 注册 HR 用户。
2. 登录后进入数据看板。
3. 确认不同角色菜单不同：求职者仅看到简历防御入口，审计员看到合规/看板入口。

## 3. JD 智能审计

输入样例：

```text
招聘男性后端工程师，35岁以下，985/211 优先，能适应高强度工作。
```

预期展示：性别、年龄、学历偏见与修改建议。

## 4. 简历防御盾

输入样例：

```text
张明，男，32岁，来自山东省。拥有 8 年 Python/FastAPI 后端开发经验。
```

预期展示：敏感字段、ATS 通过率、偏见免疫改写。

## 5. AI 面试监控

导入两组候选人面试评分，观察 4/5 法则、差异影响比、启发式解释与整改建议。

## 6. 合规报告

进入合规报告页，加载 EU AI Act 与中国 AI 伦理检查清单。

## 7. Dashboard

回到数据看板，查看数据库聚合后的 JD、简历、面试、合规指标。
